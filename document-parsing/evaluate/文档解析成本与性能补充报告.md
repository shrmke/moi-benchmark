# 文档解析成本与性能补充报告

统计日期：2026-09-18。比较 MOI IDC 4.1.14、MinerU Precision API 和百度 PaddleOCR-VL API；不包含后续 MOI Enhanced 实验。

## 1. 主要结论

- MOI 的 VLM API 等价成本：OmniDocBench **￥22.84/千页**，私有数据集 **￥20.46/千页**。这是按 token 折算的参考成本，不是自部署实付或完整链路成本。
- MinerU API **免费**，暂无商业化收费计划；Paddle 免费200页，超额按量 **￥90/千页**，资源包 **￥30–46/千页**。
- 私有集50份已重新调用两家官方API：按各自非空结果统计，MinerU **2.66秒/页**、Paddle **2.58秒/页**；相同48份非空文件上，两者均约 **2.61秒/页**。这是整份累计耗时摊到参考页数，不是真实逐页延迟。
- Omni竞品暂只有单页样本：MinerU约18.45秒、Paddle约9.43秒到成功。MOI和竞品计时边界不同，不能直接作速度排名。
- **实测吞吐量、GPU/内存占用、完整自部署成本仍需补测或补充成本依据。**

## 2. 主要对比数据

### 解析质量

| 数据集 | MOI | MinerU | Paddle |
|---|---:|---:|---:|
| OmniDocBench，1651页，Overall | **90.23** | MinerU-2.5：93.04 | PaddleOCR-VL：94.18 |
| 私有集，50份文件，维度等权分 | **84.5%** | 56.8% | 58.6% |
| 私有集，文件内元素数量加权分 | **89.4%** | 66.7% | 70.5% |

Omni 的 MOI 为本地正式实测，竞品为既有报告记录的官方 v1.6_full 榜单，不是当前在线 API 同批实测；私有集三方均基于实际解析结果评分，两个总分都在50个文件间等权平均。两套数据集评分机制不同，分数不能合并。

MinerU 免费，分母为0，成本倍率不适用。Paddle 资源包有效期12个月，单价以全部用完为前提；未抵扣200页免费额度，不能在两个实验中重复抵扣。私有实验用户回忆 Paddle 实付约￥1，尚未核验账单。

**MOI 折算依据：** 从 ZIP 内 `*_performance.json` 汇总全部 VLM 输入/输出 token；成本按实际调用所用模型的对应单价计算后，再按数据集汇总。

| 数据集 | 文件数 | 页数 | 输入 token | 输出 token | API 等价总成本 |
|---|---:|---:|---:|---:|---:|
| OmniDocBench | 1651 | 1651 | 45,615,121 | 2,153,523 | **￥37.71** |
| 私有集 | 50 | 200 | 2,440,898 | 234,748 | **￥4.09** |

单价参考当前[官方 API 价格](https://help.aliyun.com/en/model-studio/model-pricing)。未逐请求核验计费档位，不计缓存、Batch或免费优惠；这是等价估算，不是实际账单。

成本公式：`各次调用的（输入token × 对应输入单价 + 输出token × 对应输出单价）求和 ÷ 100万 ÷ 页数 × 1000`。

两批记录32/3次 VLM 失败调用，汇总日志未单独拆出失败token，**尚未严格落实排除失败成本的要求**。按用户要求暂不计自部署MinerU；本地Paddle、宿主机及折旧未定价，因此以上倍率不代表MOI三段链路完整成本。

### 耗时

P50/P95/P99分别表示50%/95%/99%的样本在对应时间内完成，不是平均值。

| MOI 历史实验 | P50 | P95 | P99 |
|---|---:|---:|---:|
| Omni 单页内部解析耗时 | **42.18秒** | **86.29秒** | **114.44秒** |
| 私有集单文件耗时 | 62.68秒 | 217.85秒 | 270.87秒 |
| 私有集文件耗时÷页数 | **23.30秒/页** | **58.44秒/页** | **69.79秒/页** |

MOI 时间取自 `total_elapsed_seconds`，不含完整上传、排队、Office→PDF转换、结果导出和下载。私有集最后一行是50个文件平均每页耗时的分位数，不是200页的真实逐页延迟；分位数使用线性插值。

**私有集官方API全量重跑（2026-09-18）**：50份原始文件与正式实验manifest的哈希一致。两家并行测试，各自单文件串行提交，轮询间隔1秒，沿用历史API参数。

| API | 接口成功文件数 | 非空结果数 | 对应参考页数 | 非空结果累计耗时 | 平均每份 | 平均每页 |
|---|---:|---:|---:|---:|---:|---:|
| MinerU Precision，vlm | 49/50 | 49/50 | 187 | 497.92秒 | 10.16秒 | **2.66秒** |
| PaddleOCR-VL | 50/50 | 49/50 | 199 | 512.47秒 | 10.46秒 | **2.58秒** |

平均每页 = 非空结果累计耗时÷对应MOI渲染参考页数。只比较两家均成功且非空的 **相同48份、186参考页**：MinerU **2.608秒/页**，Paddle **2.614秒/页**，均约2.61秒/页。结果非空只做基本检查，不代表内容正确，本次未重新评分。

| 私有非空结果的单文件API耗时 | P50 | P95 | P99 |
|---|---:|---:|---:|
| MinerU | 8.59秒 | 20.17秒 | 24.95秒 |
| Paddle | 6.24秒 | 26.10秒 | 44.68秒 |

以上是文件级分位数，不能标成逐页P50/P95/P99。时间从提交/申请上传地址前到轮询检测成功，含网络、上传、服务排队和解析，不含鉴权初始化和下载；页数统一取MOI日志参考页数，因为Office原生解析不一定对应物理分页。Paddle接口返回的总页数为199，与MOI参考200页略有差异。

失败项：MinerU的 `12测试跨页表的拼接.pdf`（13页）两次均报 `parsing failed, please try again later`；Paddle的 `86PPT板式识别不好9台.pptx` 返回成功，但正文/版面/图片/表格均为空。表中排除失败、重试等待及空结果。重跑可能包含服务端缓存或结果复用，未控制冷启动，不能当作纯模型推理性能。

新结果、每文件耗时、任务ID和汇总统计保存在本地 `runs/private-official-api-latency-20260918/`。该原始结果目录较大，未随本报告提交；旧正式结果未覆盖。当前API模型未锁定为历史评分版本。

**Omni竞品单页样本**仍为：MinerU18.45秒、Paddle9.43秒到成功；下载完成分别18.73/10.24秒。只有各一次，不能代表全量均值或分位数；私有平均耗时以上述全量重跑为准。

复现脚本：[measure_private_competitor_api_latency.py](../scripts/measure_private_competitor_api_latency.py)。读取 `MINERU_API_TOKEN`、`BAIDU_OCR_API_KEY`、`BAIDU_OCR_SECRET_KEY` 环境变量；传入 `--output` 指定新目录运行。对已有结果加 `--summarize-only` 可不调用API重新统计；`--provider mineru --retry-failed` 可显式重试失败文件并保留旧记录。Python使用项目统一 `.venv`。

### 自部署电费估算

用户确认VLM部署在六卡RTX 4090上。假设整机平均3kW、电价￥0.80/kWh、散热系数1.2，并在全部解析时间内独占机器，则电费约为：

| 场景估算 | OmniDocBench | 私有集 |
|---|---:|---:|
| 每千页电费 | **￥38.12** | **￥16.80** |

公式：`逐文件耗时之和 ÷ 3600 ÷ 总页数 × 1000 × 3 × 0.8 × 1.2`。这是场景假设，不是实测耗电；实际并发、共享、GPU负载和历史部署均未确认。**电费不能与API等价成本相加**，二者是不同成本口径。

MOI组合链路为本地CPU `PP-DocLayout_plus-L` → 自部署MinerU `v2.7.4` / `MinerU2.5-2509-1.2B` → VLM后处理。

原始日志保存在本地 `runs/omnidocbench-idc-4.1.14-vlm-final-1651/` 和 `runs/半导体场景私有数据集-idc-4.1.14/`；其中 Omni 原始结果未随本报告提交。完整质量和配置说明见[Omni评测分析](MOI_OmniDocBench评测分析.md)、[私有评测报告](半导体场景私有数据集评测报告.md)。竞品价格依据用户提供的官网说明及Paddle购买页截图；MinerU条款为50文件/分钟、5000文件/天，结果查询1000次/分钟，限流可动态调整。
