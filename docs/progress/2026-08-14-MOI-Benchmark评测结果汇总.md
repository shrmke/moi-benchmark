结论：LandingAI 的整体开箱准确率更高，三数据集平均 F1 领先 5.20pp，文档全对率领先 6.29pp。MOI 在 VRDU 上已接近 LandingAI，并呈现更保守的填值策略：Precision 为 70.26%（LandingAI 66.01%），空字段误提率为 20.83%（LandingAI 49.31%）；LandingAI 则以更高 Recall 取得略高的总体 F1。两项产品对 Kleister-NDA 均未达到可直接无人审核入库的水平。

## 6. NL2SQL

本轮完成 Enron 私有邮件数据集和 Spider Mix50 公开数据集两套可复现评测。三个产品统一使用 `qwen3.7-plus-2026-05-26`，以减少基础模型差异，使结果主要反映产品的 Schema 探索、语义理解、SQL 生成、反思修正和执行能力。

评测不把准确率、成功率、延时和 Token 合成为一个总分。SQL 成功率只表示 SQL 能够生成并执行，不代表查询结果正确；执行正确率通过候选 SQL 与 Golden SQL 的执行结果比较得到；P50、P95 分别反映典型等待时间和慢请求长尾。

### 6.1 统一条件与产品路径

| 产品    | 部署方式                       | 数据与执行路径                                           | 业务语义配置                                        | 统一模型                    |
| ------- | ------------------------------ | -------------------------------------------------------- | --------------------------------------------------- | --------------------------- |
| MOI     | 本地 Matrixflow/MOI            | 同源数据导入 MatrixOne 知识库，由 MOI 原生生成并执行 SQL | Enron 同时测试有语义、无语义；Spider 不注入额外语义 | `qwen3.7-plus-2026-05-26` |
| Wren AI | 本地 Docker 部署 Canner/WrenAI | 连接本地 MySQL；候选 SQL 在 MySQL 快照执行               | 无专门业务语义                                      | `qwen3.7-plus-2026-05-26` |
| Chat2DB | 购买会员的商业桌面软件         | 连接与 Wren 相同的本地 MySQL；候选 SQL 在 MySQL 快照执行 | 无专门业务语义                                      | `qwen3.7-plus-2026-05-26` |

MOI 采用 MatrixOne 原生产品路径，因此其执行结果与 Golden SQL 在 MySQL 中的结果进行规范化比较；Wren 和 Chat2DB 则直接在同一 MySQL 快照中比较。该设计保留了产品真实使用方式，但 MatrixOne 与 MySQL 的大小写、排序、日期函数和空值行为差异仍需在人工审核中识别。

### 6.2 Enron 私有数据集

Enron 数据库包含 6 张表、32 个字段和 10,401 封邮件，覆盖邮件正文、当前邮件头、历史引用邮件头、标准收件邮箱、展示收件人和邮件来源目录。50 题包含 Easy 20 题、Medium 20 题、Hard 10 题；明确语义题和用户口语化题各 25 题。每题使用独立会话运行 3 次，共 150 次请求，用于同时评估正确性和重复稳定性。

#### 6.2.1 自动严格评测

#### 6.2.2 人工审核结果

人工审核只复核自动判错或存在语义争议的记录，并保留逐题、逐轮标签。严格正确率只计算完全正确；加权正确率把“核心语义正确但存在非关键列、排序或展示问题”的部分正确记为 0.5 分。

## 8. 汇总结论

1. **Astra**：两个 benchmark 的通过率均低于 Hermes/PI，优势是部分任务具有独占通过能力，且可靠 Token 记录的单任务消耗相对较低，尤其是输入token相对最低。主要短板在于长任务规划自检、请求控制和对网络波动的鲁棒性。
2. **Memoria**：LongMemEval-S 已达到或略高于公开竞品参照，LoCoMo 仍有约 3.6～4.6pp 差距；在 Feature 评测中，快照与回滚、分支/Diff/Merge、低置信记忆治理等 Memoria 特有能力表现稳定，其他竞品目前不具备同构能力；语义等价记忆处理仍有优化空间。
3. **文档解析**：MOI 在 OmniDocBench 上处于 MinerU-Pipeline 之上、MinerU-2.5 和新版 PaddleOCR-VL 之下；在半导体行业私有集上则显著领先 MinerU Precision 和 PaddleOCR-VL，体现出复杂、多页和跨页文档场景优势。
4. **信息提取**：LandingAI 目前整体领先；MOI 在 VRDU 监管表单上差距较小，并在 Precision、文档全对率和空值控制上具有局部优势。
5. **NL2SQL**：统一模型后，MOI 的 Enron 语义配置使人工严格正确率提升 10pp、口语题提升 20pp；Spider Mix50 单轮中 Wren 严格执行正确率为 84%，MOI 与 Chat2DB 为 80%，其中 MOI 和 Chat2DB 均达到 100% SQL 成功率。准确率、稳定性、延时和 Token 应分别报告，不合并为单一总分。
6. **RAG**：四个平台在五类数据集上没有一致最优者。MOI 的文本链路稳定，在关键词覆盖、布局召回、企业检索降噪和完整性上表现突出；高 K 完整证据集召回、答案覆盖以及 DocBench 总体和多模态正确率仍需加强。

以上六项评测均已完成；本汇总后续仅在其他评测方向产生正式结果后继续补充范围。
